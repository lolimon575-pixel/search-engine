# NOVA Search

Экспериментальный поисковик с технической проверкой сайтов и отдельным слоем подтверждения официальности.

## Локальный запуск
```
python -m venv .venv
pip install -r requirements.txt
cd backend
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Открыть: http://127.0.0.1:8000/

## Render
Build: `pip install -r requirements.txt`
Start: `cd backend && uvicorn app.main:app --host 0.0.0.0 --port $PORT`
Health: `/health`

NOVA сообщает результаты технических проверок и уровень подтверждения официальности на момент проверки. Это не гарантия безопасности, законности или добросовестности сайта.

## Направление развития

NOVA развивается как слой доверенного поиска: реестр официальных организаций, проверка источников и собственный индекс знаний поверх обычного веб-поиска.

NOVA Index использует собственный полнотекстовый индекс SQLite FTS5 и BM25: названия компаний, домены, официальные разделы и метаданные ранее найденных публичных страниц. Платный профиль не добавляет баллы ранжирования.

- **Авто**: ответ из индекса сразу; DuckDuckGo дополняет выдачу в фоне.
- **Индекс NOVA**: только локальная выдача, без запросов к внешнему поисковому провайдеру.
- **Веб**: внешняя выдача с ранжированием и проверками NOVA.

Сопоставление домена с курируемым реестром выполняется без сети. DNS, HTTPS, HTTP, редиректы и внешнее подтверждение проверяются отдельно в фоне. До завершения проверки технический статус остаётся `UNKNOWN`. Фильтр даты использует веб-поиск: время добавления страницы в индекс не считается датой публикации.

Индекс ограничен 5000 документами; найденные страницы устаревают через 14 дней. При наличии существующей PostgreSQL базы публичные названия, URL и сниппеты сохраняются и восстанавливаются в фоне. Тексты запросов в этой таблице не хранятся. Без базы изученные страницы остаются в памяти до перезапуска; курируемая часть восстанавливается из кода. Это начальный индекс, а не самостоятельный обход всего интернета.

Поисковый кэш ограничен 256 запросами на 90 секунд. Одновременно допускаются 12 заданий веб-поиска и 64 технические проверки; одинаковые запросы объединяются. API возвращает `search_pending`, `verification_pending`, `source` и `server_time_ms`; клиент обновляет ответ последовательно, сохраняя исходные фильтры. Время первой выдачи не подменяется временем пустого промежуточного ответа.

## Проверка скорости и тесты

```bash
PYTHONPATH=backend python backend/scripts/benchmark_search.py
PYTHONPATH=backend python -m pytest backend/tests -q
node --test frontend/tests/*.test.cjs
```

Бенчмарк измеряет локальное получение результатов и сопоставление с реестром без сети. Для реального времени ответа дополнительно учитываются сеть, запуск сервера после простоя и отрисовка браузера. На бесплатном Render холодный запуск и скорость внешнего провайдера остаются отдельными ограничениями.
